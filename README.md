## 什么人能领？新用户判定比你想的严

免费试用只面向新用户，而且“新用户”的判定比“刚注册”严格得多，很多人领不了就是卡在这一步。

产品试用的基础门槛有四条：注册阿里云账号；完成个人实名认证或企业认证；账号没有欠费；虚商账号和RAM用户（子账号）不能参加。解决方案试用在这之外还要求绑定安全手机号。

产品试用还有一条“产品新用户”规则，官方的定义是“三无”：

- 在这款产品上没有过大于等于0元的新购订单——0元订单也算
- 没有产生过大于等于0元的后付费账单
- 历史上没有试用过这款产品

三条里中任何一条，这款产品就和你无缘了。同一类产品只能领一种规格：以云服务器为例，官方示例里试用了1核2G之后，就不能再申请2核4G的试用，但换个品类——比如从没碰过OSS——照样能领。

同人限制也要留意。同一证件、同一手机号、同一邮箱注册的账号，都算同一个人，只能用其中一个账号参与试用，换个手机号重新注册来“刷新”资格走不通。个人认证和企业认证能领的产品清单也不一样；个人账号试用过的产品，升级成企业账号后同样不能再试同一款。

最后一个容易被忽略的时机问题：试用资源要在产品服务功能开通之前领取。一旦你从别的入口把服务开通了，系统会把你识别成非新用户，试用权益就没了。想领试用，务必从免费试用中心进入。

## 免费试用会在哪里产生费用？

试用本身免费，但官方文档列出了几类按标准资费扣钱的情况，都和“超”字有关。

**超出免费额度**。额度型产品用超了，超出部分正常出账；按量付费的试用实例超额后实例不停机，按实际用量计费。想控制成本，就在“我的试用”里盯着“周期内试用进度”看。

**到期不处理**。后付费用户最容易中招的一条：试用结束后，只要账户里有余额，系统会按使用量自动扣费，实例不会自动停，不需要就手动释放。预付费（包年包月）的试用产品则相反，到期后自动关闭并释放实例。

**用了非免费功能**。升级固定带宽、系统盘超出范围、按量付费转包年包月，这些操作超出免费范围的部分都会计费。试用产品变配前，先查对应产品的文档确认是否支持、是否产生费用。

**自己买的资源包会优先被扣**。这条很反直觉：假如OSS给你3个月免费20GB资源包，你中途自己又买了40GB，后续使用会先扣你买的40GB，扣完才开始动免费的那20GB。免费额度不会因为你有付费资源包就被优先保护。

另外两条红线：试用资源禁止用来挖矿，被发现会被收费并取消资格；真出现了非预期扣费，官方页面的承诺是支持退款，先到“我的试用”里查清楚是哪项超了。

## 试用到期后，数据和续费怎么办？

到期后数据不会立刻消失，但保留期不长：各产品规则不同，一般是1~15天，之后实例释放、数据清理，释放后无法找回。重要数据务必在到期前备份。到期前官方会通过邮件和站内信提醒，收到提醒就该做决定了。

续费分两种情况。包年包月的试用实例不用等到期，随时可以在“我的试用”页面续费，续了有效期自动延长；按量付费的没有“续费”一说，账户余额够就自动扣，不想用了手动释放即可。释放掉的试用实例无法找回，释放后也不能再参与同一产品的免费试用。

## 几个高频问题

**为什么提示“不符合试用规则”？**
把鼠标停在置灰的“立即试用”按钮上，系统会显示具体原因。常见原因就四种：没完成实名认证；这款产品以前试用或购买过；同人账号已经参与过；没有从试用中心页面进入开通。

**试用额度没用完，能攒到下个月吗？**
不能，额度仅限当月使用，过期清零。

**试用机器能换地域吗？**
不能。云产品开通后不支持直接变更地域和可用区，领取时就要选好。

**试用中能升级配置吗？**
部分产品支持变配，先去产品文档确认；变配可能产生额外费用，按需选择。

**人在海外，用阿里云国际站，规则一样吗？**
不一样。国际站是另一套免费试用体系：80多款产品、最长12个月，试用期间需要持续绑定信用卡或借记卡这类支付方式，条款和国内站不同，具体以国际站页面为准。

**解决方案的试用点能拿来试用普通产品吗？**
不能。试用点专用于解决方案验证时的资源抵扣，和产品试用是两套独立额度。
